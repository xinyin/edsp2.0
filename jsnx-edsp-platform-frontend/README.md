# EDSP 2.0 平台前端

独立 Vue 3 + TypeScript + Element Plus 工程，开发端口 `5173`。前端只负责平台运营工作台，不包含供应商应用页面。

## 功能模块

- 工作概览：全平台调用量、成功率、计费金额和资源健康驾驶舱。
- 供应商能力接入：读取供应商开放目录，实时发现新增数据源和 API。
- 服务商管理：供应商资料、账号、角色和权限。
- 数据资源服务：数据源独立部署单元、API 配置、字段标准化、安全策略和联调测试。
- 审批中心与服务授权：版本审批、机构/系统授权和配额管理。
- 计费管理：按统一返回状态生成计量规则和费用汇总。
- 调用日志与监控运维：Trace 链路、节点入参出参、耗时、异常和告警。

## 运行模式

- `VITE_DEMO_MODE=mock`：不依赖后端，可演示页面交互。
- 默认模式：通过 `/api` 调用平台后端，通过 `/vendor-api` 调用供应商应用。

```bash
npm install
npm run dev
npm run build
```
