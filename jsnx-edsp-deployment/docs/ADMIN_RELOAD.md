# 本地 Demo 管理服务更新

## API 删除提示 405

如果前端已经出现“删除 API”，但 Admin 日志提示 Request method 'DELETE' is not supported，说明正在运行的 Admin 仍未加载新接口。仅打包 JAR 不会替换已启动的 JVM。

在部署工程中执行：

```bash
bash ./bin/restart-admin.sh
```

脚本会构建 Admin 和依赖组件、校验当前 PID 及工作目录、停止旧 Admin、启动新版，并通过 OPTIONS 确认 DELETE 方法已加载。它不执行 schema.sql 或 data.sql，不重新初始化数据库，也不重启 Gateway、资源提供商或数据应用。Admin 重启期间管理页面可能短暂不可用。若运行时使用了自定义 DB_URL、DB_USERNAME、DB_PASSWORD 等环境变量，应在执行该脚本的终端沿用相同变量。

前端开发模式下刷新页面即可加载界面更新；静态部署需发布前端 dist 构建产物。

## 删除行为

- 入口：数据资源服务 → 选中 API → 编辑区右上角“删除 API”。
- 仅未发布、无待处理审批的草稿允许删除；已发布 API 的删除按钮禁用。
- 删除操作为软删除，历史调用和关联记录保留。
- 重复删除同一记录不会报错。
- 已删除 API 的旧编辑页面不能通过保存或审批恢复接口。

## 页面变化

已移除静态部署示意、假定双实例可用提示。基本信息页采用“行内调用入口、上游连接、请求超时、当前配置预览”布局。地址和超时预览随输入变化；保存草稿与正式发布的提示区分展示。
