# 外部数据平台产品文档

本目录对应 2026-10-09 仓库实现，不将规划能力或模拟机制表述为已通过生产验收。

- `01 产品功能介绍.docx`：产品定位、功能模块、资源与标准服务关系、配置能力和交付边界。
- `02 使用手册.docx`：启动登录、资源接入、标准服务开发、上线下线、授权、Postman 调用及排障。
- `03 详细设计与数据库设计.docx`：技术架构、公共组件、动态路由、计划热更新、版本生命周期、日志计量、接口目录、平台与供应商共 24 张表的字段、约束及用途。
- `完整调用链路图.png`：可直接使用的调用图。
- `完整调用链路图.svg`：可缩放矢量图。
- `完整调用链路图.mmd`：调用时序的 Mermaid 源文件。

生成器位于上级目录 `build_product_docs.py`，依赖 Python、python-docx、Pillow 和 macOS Heiti 字体。从仓库根目录执行 `python3 jsnx-edsp-deployment/docs/build_product_docs.py` 可重建。

数据库字段从仓库 schema.sql 提取；已运行环境应另与 SHOW CREATE TABLE 比对历史迁移差异。文档不包含业务数据导出。
